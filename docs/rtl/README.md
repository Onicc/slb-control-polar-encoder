# Verilog RTL And cocotb Verification

This directory documents the Verilog implementation of the SLB control
information Polar encoder.

## RTL Scope

The RTL top level is:

```text
rtl/slb_control_polar_encoder.v
```

It implements one control-information code block at a time:

```text
c_r + K + E0 + E + rvid -> f_r
```

The C++ library supports multi-block concatenation as `g = f_0 || f_1 || ...`.
The RTL keeps this boundary explicit so a hardware system can reuse the single
block engine for each code block and concatenate at the scheduler/buffer layer.

## Interface

Main inputs:

| Port | Width | Meaning |
|---|---:|---|
| `clk` | 1 | Clock |
| `rst_n` | 1 | Active-low reset |
| `start_i` | 1 | Start pulse |
| `k_i` | 11 | Number of input information bits |
| `e0_i` | 14 | First-transmission rate-matched length `E0` |
| `e_i` | 14 | Current-transmission rate-matched length `E` |
| `rvid_i` | 2 | Redundancy version |
| `c_bits_i` | 1024 | Input bits, LSB-first |

Main outputs:

| Port | Width | Meaning |
|---|---:|---|
| `done_o` | 1 | Pulses high one cycle after `start_i` is sampled |
| `error_o` | 1 | Invalid input flag |
| `out_len_o` | 14 | Valid output bit count |
| `f_bits_o` | 7936 | Interleaved output bits, LSB-first |
| `n_len_o` | 11 | Selected Polar mother code length |
| `n_exp_o` | 4 | Selected `n`, where `N=2^n` |
| `npc_o` | 2 | Number of PC bits |
| `npc_wm_o` | 2 | Number of row-weight-selected PC bits |
| `m_o` | 14 | Rate-match circular-buffer length |
| `k0_o` | 14 | Rate-match circular-buffer start |

## Generated Tables

`rtl/slb_polar_tables.vh` is generated by:

```sh
python3 scripts/generate_rtl_tables.py
```

It contains:

- `Q_1024`, derived from the integrated Table C.1 sequence;
- the three fixed `Iseq` interleaver permutations.

The generator validates the source C.1 table and the interleaver permutations
before writing the Verilog include file.

## Run cocotb With Icarus Verilog

Create the virtual environment:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-cocotb.txt
```

Run through the cocotb Makefile:

```sh
PATH="$PWD/.venv/bin:$PATH" make -C sim/cocotb
```

Run through pytest and `cocotb-test`:

```sh
.venv/bin/python -m pytest tests/cocotb -q
```

## Verification Coverage

The cocotb tests cover:

- standard Table C.1-derived `Q_1024`;
- no-PC and PC control-information branches;
- `nPCwm=0` and `nPCwm=1`;
- rate matching for all four `rvid` values;
- punching and shortening parameter branches;
- interleaver ordering;
- invalid parameter cases;
- a deterministic sweep of 780 valid scenarios.

The Python reference model lives in:

```text
sim/cocotb/slb_reference.py
```

It independently recomputes the expected output and debug parameters used by
the cocotb checks.
